\subsection{Indentation Character}\label{sec:IndentationCharacter}
As said, you should use four \textit{blanks}\index{indentation!character}; do \textit{not} use tabs (\lstinline|'\t'|, ASCII~9\index{ASCII} or 0x09)! Tabs are \textit{not} allowed! This is different from the \bdq{Code Conventions for the \Java Programming Language}\index{Code Conventions for the Java Programming Language} \autocite{SUN_CODE_CONVENTIONS:Indentation} that do not explicitly specify whether to use blanks or tabs.

Usually both, the indentation character\index{indentation!character} and the indentation base unit\index{indentation!base unit} can be configured in your IDE; in Eclipse IDE\index{Eclipse!IDE} this is part of the \textit{Formatter} definition (\texttt{Window|Preferences|Java|Code Style|Formatter}).

In IntelliJ~IDEA\index{IntelliJ IDEA}, this setting is part of the Code~Style configuration for Java (\texttt{File|Settings|Editor|Code Style|Java|Tabs and Indents}).
