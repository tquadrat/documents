\section{Library File Names}\label{sec:LibraryFiles}
The results from Java projects are usually delivered as \verb#*.jar# files (\bdq{jar} stands for \bdq{Java Archive}), and it may contain libraries as well as programs that can be directly executed – some even do contain both.

Other outcomes could be \verb#.ear# and \verb#.war# files, for JEE and for Web Applications.

If there are no other constraints for the naming of these outcomes it appears to be a good idea to name them after the project (refer to the chapter \hyperref[sec:Projects]{above}), appended by a version number and/or a release date. Of course, the final name have to be valid file name.\footnote{That means usually that it may not contain colons, slashes and backslashes.}
