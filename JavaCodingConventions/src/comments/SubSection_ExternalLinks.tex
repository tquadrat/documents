\subsection{Links to external Documentation}
If the option \mbox{\bsq{\texttt{-{}-no-platform-links}}} is not specified on the command line, Javadoc\index{javadoc} automatically generates links for the \Java Runtime Library.

It is also possible to add links to the Javadoc\index{javadoc} generated documentation of other external libraries.

For that you add a \mbox{\bsq{\texttt{-link}}} option to the command line of the \texttt{javadoc}\index{javadoc} command. It takes the URL for that external documentation as the argument. This is the base URL for the generated links in your documentation. It is important that the URL points to a directory containing either a \mbox{\texttt{package-list}} or an \mbox{\texttt{element-list}} file. These had been generated by the Javadoc\index{javadoc} tool when the external documentation was generated.

The \mbox{\bsq{\texttt{-link}}} option requires that the machine executing the \texttt{javadoc}\index{javadoc} command has internet access to the location of the external documentation. If this is not possible, you can use the \mbox{\bsq{\texttt{-linkoffline}}} option instead of \mbox{\bsq{\texttt{-link}}}.

The \mbox{\bsq{\texttt{-linkoffline}}} option takes two URLs; the first is again the base URL for the generated links in your documentation. But the second URI determines the location of the  \mbox{\texttt{package-list}} or \mbox{\texttt{element-list}} file, and this can point to the location of a local copy of these files.

This option can also be used if the \mbox{\texttt{package-list}} or \mbox{\texttt{element-list}} file is inaccessible at its standard location determined by the base URL.

Add one \mbox{\bsq{\texttt{-link}}} or \mbox{\bsq{\texttt{-linkoffline}}} for each external library whose documentation you want to link to.

\subsubsection{The Command Line Options}

\paragraph{\texttt{-link}} Enables the generation of links into the specified external documentation.

\paragraph{\texttt{-linkoffline}} Enables the generation of links into the specified external documentation in cases it cannot be accessed online.

\paragraph{\texttt{-{}-no-platform-links}} If set, no links into the runtime library will be generated.
