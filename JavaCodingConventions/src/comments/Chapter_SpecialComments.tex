\chapter{Special Comments}
The \ccjpl suggests some special comments \autocite{SUN_CODE_CONVENTIONS:SpecialComments}:
\begin{itemize}
	\item{\lstinline|XXX| in a comment flags something that is bogus but works.}
	\item{\lstinline|FIXME| flags something that is bogus and broken (and has to be fixed very soon).}
\end{itemize}

The Eclipse IDE knows a setting that allows to externalise such comments into a task list:\\ \verb#Window|Preferences|General|Editors|Structured Text Editors|Task Tags#.

It also adds \bdq{\lstinline|TODO|} to that list, for something that still needs to be implemented.
