\subsection{Links to external Documentation}
If the option \bsq{\texttt{-{}-no-platform-links}} is not specified on the command line, Javadoc\index{javadoc} automatically generates links for the \Java Runtime Library.

It can also add links for other external libraries to to their Javadoc generated documentation.
