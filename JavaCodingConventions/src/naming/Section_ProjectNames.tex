\section{Project Names}\label{sec:Projects}
Projects are not a part of the \Java programming language. They were introduced by the various IDEs for the language.

You can name your project however you want, although some IDEs have some constraints about the exact format.

I recommend to name the project after the module; for the name of a module refer to \tqfullvref{sec:Modules}.
