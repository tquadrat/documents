\subsection{The \bsq{Overview}}\label{sec:OverviewDoc}
The overview is not a typical documentation comment; its source is an HTML\index{HTML} document that is referenced through the command line parameter \verb#-overview <filename># (see \autocite{ORACLE_DOC_JAVADOC_MAN:StandardDocletOptions}) when the Javadoc tool\index{javadoc} is called to generate the documentation for your project. Obviously, \verb#<filename># is the (fully-qualified)  filename of that file. The recommended name is \verb#overview.html#.


\subsubsection{The Overview Comment}\label{sec:OverviewComment}
When the JavaDoc tool is called with the option , an ‘Overview’ comment is  added to the generated documentation. \verb#<filename># is the (fully-qualified)  filename of a valid HTML~5 document ( containing general information about the project.

You can put nearly everything here, from the project's history to manual on how to use the program or library, but you should not reproduce information that is given in the module, package, or class documentation comments.

Several JavaDoc tags can be also used in the overview comment; for details refer to the chapter "Where Tags Can Be Used" in \autocite{ORACLE_DOC_JAVADOC_TAG}.
