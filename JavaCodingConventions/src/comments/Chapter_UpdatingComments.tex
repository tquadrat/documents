\chapter{Updating Comments}
When the source code is modified, no matter if due to regular maintenance, bug fixing or a migration, all related comments has to be updated accordingly. That is mandatory!

There is no value in keeping \bdq{historical comments}, although mentioning the old algorithm when the former implementation has been replaced completely might be useful in some cases. But usually the commit messages for the SCCS\index{SCCS} should be sufficient for the explanation of the changes.

Keeping the outdated code as a comment is definitely not useful, in particular not when there is an SCCS\index{SCCS} in place that is used to manage the code.
