\section{File and Folder Names}\label{sec:FileNames}
The name for a Java source file is determined by the name of the public class\index{class!public class} contained by that file, plus the extension \verb#.java#. So the source file for the class\index{class} \lstinline|MyClass| would be named \verb#MyClass.java#.

Even on filesystems that are case-insensitive in regards to file and directory names, the casing for the filename has to match the name of the class\index{class}. 

While a source file can contain only one public class\index{class!public class}, it may contain several non-public top-level classes\index{class!non-public class}\index{class!top-level class}, The recommendation is to have only one top-level class\index{class!top-level class} per source file. That makes it easier to keep the naming consistent. Consequently the source files for non-public classes\index{class!non-public class} can be named in the same way as for public classes\index{class!public class}, by the name of the class\index{class}.

The package\index{package} that a class\index{class} resides in determines the path for the source file; the dot that separates the package\index{package} names translates to the path separator used by the file systems where the files are stored. Again, the package\index{package} names are case-sensitive.

Some examples for the names of Java source files; here \verb#<srcroot># stands for the base folder of the source tree:

\begin{tabular}{|l|l|}
\hline 
\textbf{Java Class} & \textbf{Fully qualified Filename} \\ 
\hline 
\lstinline|java.lang.String| & \verb#<srcroot>/java/lang/String.java# \\ 
\lstinline|javax.xml.XMLConstants| & \verb#<srcroot>/javax/xml/XMLConstants.java# \\ 
\lstinline|org.junit.Test| & \verb#<srcroot>/org/junit/Test.java# \\ 
\lstinline|org.tquadrat.lang.Objects| & \verb#<srcroot>/org/tquadrat/lang/Objects.java# \\ 
\hline 
\end{tabular}

For the naming of classes\index{class}, refer to chapter \tqref{sec:Classes}, for the naming of packages\index{package}, see chapter \tqref{sec:Packages}.
