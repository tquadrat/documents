\section{\bsq{\textit{test}} as Part of Names}
The fragment ``\verb#test#'' should not be used as part of names for program elements of \textit{production} code. It should be reserved to \textit{test} code, and even there it should be used mainly where it is required.

Of course, if your product is a testing framework or an extension to an existing one, it might be necessary to use ``\verb#test#'' as part of the names for packages, classes, interfaces and
methods.
